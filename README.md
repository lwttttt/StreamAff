# StreamAff

**When to Respond, Where to Ground: Streaming 3D Affordance Grounding**

Wenting Luan, Weilong Yan, Siqi Lu, Ming Li, Beibei Lin, Yongbin Zheng, Robby T. Tan

Project page: https://lwttttt.github.io/StreamAff/

Paper: https://arxiv.org/abs/2611.34067

StreamAff watches an RGB-D stream and decides when to respond to a request and where to ground the requested
functional part, using only what it has observed so far. StreamFun3D is the accompanying benchmark, with four
evidence settings (Current, History, Future, Unobserved) and the StreamIoU metric.
